# دخل اليوم · Daily Income Ledger
أداة بسيطة لتسجيل دخل نهاية الدوام، جزء من مجموعة **Daily Hub** الشخصية.

## المميزات
- تسجيل حركات الدخل (مبلغ، طريقة دفع، دوام، ملاحظة) مع إجمالي فوري
- ساعة حية + التاريخ الميلادي والهجري
- عربي / إنجليزي — داكن / فاتح
- تصدير JSON و Excel، واستيراد JSON
- طباعة تقرير شهري بشكل جدول (كل شهر بصفحة منفصلة مع إجمالي، وإجمالي كلي في آخر صفحة)
- مزامنة تلقائية اختيارية مع GitHub، بحيث تكون البيانات محفوظة بشكل دائم بغض النظر عن الجهاز أو المتصفح

## الهيكل
```
index.html            الأداة نفسها (ملف واحد مستقل)
data/daily-income.json ملف البيانات المستخدم في مزامنة GitHub (يُنشأ/يُحدَّث تلقائياً من داخل الأداة)
```

## التشغيل
افتح `index.html` مباشرة من أي متصفح، أو فعّل GitHub Pages على هذا المستودع
(Settings → Pages → Branch: main → Save) وافتح الرابط الناتج.

## تفعيل مزامنة GitHub (اختياري لكن يُنصح به بشدة)
البيانات تُحفظ محلياً في متصفحك تلقائياً، لكن التخزين المحلي (localStorage) خاص بكل
رابط/نطاق على حدة — فإذا فتحت الأداة من رابط مختلف أو جهاز آخر لن ترى نفس البيانات
إلا إذا فعّلت هذه المزامنة، والتي تجعل هذا المستودع هو المصدر الموحّد للبيانات.

1. أنشئ **Fine-grained Personal Access Token** من
   `GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens`
   - **Repository access**: حدده على هذا المستودع فقط
   - **Permissions**: `Contents` → **Read and write** فقط، بدون أي صلاحية إضافية
2. داخل الأداة، اضغط زر ☁️ أعلى الصفحة وعبّي:
   - اسم المستخدم / المنظمة
   - اسم هذا المستودع
   - مسار ملف البيانات: `data/daily-income.json`
   - الفرع: `main`
   - التوكن الذي أنشأته
3. احفظ — من الآن كل إضافة أو حذف يُرفع تلقائياً، وعند فتح الأداة من أي مكان تُسحب
   وتُدمج البيانات تلقائياً من هذا الملف.

⚠️ التوكن يُحفظ فقط داخل متصفحك (localStorage) ولا يُكتب أبداً داخل أي ملف من ملفات
هذا المستودع، لأن صفحة GitHub Pages نفسها عامة وأي توكن مكتوب داخلها سيكون مكشوفاً
للجميع.
